# 🤖 AI Text Summarizer

## 📌 Description

AI Text Summarizer is a Python desktop application that uses the **Groq API** and the **Llama 3.3 70B Versatile** model to generate short, clear summaries from long pieces of text.

The application provides a simple Tkinter-based graphical interface where users can paste text, generate an AI-powered summary, save the summary to a file, load previously saved summaries, and clear the interface.

---

## ✨ Features

* 🤖 AI-powered text summarization
* 📝 Paste long text for summarization
* 💾 Save generated summaries
* 📂 Load previously saved summaries
* 🗑️ Clear input and output

## 🚀 How It Works

1. Paste text into the input box.
2. Click **Summarize**.
3. The application sends the text to the Groq AI model.
4. The AI generates a concise summary.
5. The summary is displayed in the output box.
6. Users can save or load summaries at any time.

## 📦 Installation

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Install the required package.

```bash
pip install groq
```

3. Set your Groq API key.

**Windows (Command Prompt)**

```bash
set GROQ_API_KEY=your_api_key_here
```

**PowerShell**

```powershell
$env:GROQ_API_KEY="your_api_key_here"
```

4. Run the application.

```bash
python main.py
```
